## usage

this repo uses kite connect to get ticker data (price, volume, etc). the api keys should be stored in a .env file (ive included a .env.example file for reference)

two main api keys are needed- the kite connect api key and api secret

also the notebook at notebooks\kiteconnect.ipynb shows how to use kite connect
